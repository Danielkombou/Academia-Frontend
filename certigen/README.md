# CertiGen

CertiGen is a fast and efficient bulk certificate generator web application built with React, TypeScript, and Vite. It allows educators, event organizers, and organizations to upload a certificate template (PNG/PDF), upload a recipient spreadsheet (CSV/Excel), map columns, preview certificates, and instantly generate and download hundreds of personalized certificates.

## Features

- **Template Upload:** Support for PNG/PDF certificate background templates.
- **Data Import:** Upload spreadsheet data (CSV/Excel) containing recipient details.
- **Column Mapping:** Easily map spreadsheet columns to certificate placeholder fields (Name, Course, Date, etc.).
- **Live Preview:** Preview generated certificates with live recipient data.
- **Bulk Export:** Download certificates as a ZIP archive or individual PDFs.

## Tech Stack

- React 19
- TypeScript
- Vite
- CSS / Modern UI

## Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm

### Installation & Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Run linter
npm run lint
```
